## Evidence boundary

The data contract, split counts, temporal predictive effect, and main cost/risk effect
are reproduced. The random-split headline predictive metrics are not fully reproduced.
The paper says that hyperparameters were tuned by cross-validation and that boosting
models used early stopping, but it supplies neither search spaces, selected parameters,
nor the early-stopping validation split. The current repository uses declared,
conservative reconstructed settings and does not tune against the held-out test set.

A defensible next experiment would preregister training-only nested cross-validation
search spaces and evaluate the sealed test set once. That is a new scientific protocol
and is intentionally not performed as part of this frozen run.
